# 计划：自动并发 + /random 统计 + 自适应/复杂筛选（2026-02-19）

目标（用户需求汇总）：
- 默认 `docker compose up` 后无需手工扩容 worker：系统可依据 **令牌数量** 自动提升/降低并发能力（并保持稳定限速）。
- 管理端首页增加直观统计：`/random` 请求总数、近 1 分钟请求数、成功率、当前并发（in-flight）等。
- `/random` 增强：新增“自适应（自动识别移动/桌面）”参数；新增“横/竖图强制”参数；并补齐可组合的复杂筛选（作者/标签/分辨率 + 收藏/浏览/评论门槛 + 插画/漫画/动图等）。

交付方式：
- 以 `issues/*.csv` 为边界：每个 Issue 一个 commit，并 push 到 `test` 分支。
- 每个 Issue 先写清验收标准与可运行的测试命令；最终跑一次全量回归脚本。
